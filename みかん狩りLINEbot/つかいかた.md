# みかん狩り組合 公式LINE bot つかいかた

2026年度シーズン向け(①当番照会・FAQ フル実装/②休業連絡 簡易版/③④は工事中表示)

---

## 仕組み(ざっくり)

```
お客様がLINEで「今日」と送る
   ↓
クロコ(サーバー)がNotionの当番表を見に行く
   ↓
「本日の当番は◯◯園です」と自動で返信

各園のオーナーが「休園」ボタンをタップ
   ↓
Notionの休園連絡ログに自動記録
   ↓
観光協会が「休園状況」と送ると一覧で確認できる
```

このプログラム自体はClaude Codeが書いたものですが、**24時間動き続ける場所(サーバー)が別途必要**です。ここではCloudflare(クラウドフレア)という会社の無料サービスを使います。

---

## 最初の準備(1回だけ、少し手順が多いです)

### 1. LINE公式アカウントを作る

**名義は「三浦市観光協会」を推奨**(F項目で相談した通り、特定の個人名義にしないため)。

1. https://entry.line.biz/start/jp/ を開く
2. 観光協会の名前・住所などで法人/団体アカウントとして登録
3. 登録後、LINE Developersコンソール(https://developers.line.biz/console/)にログイン
4. 「プロバイダー」を作成 → その下に「チャネル」(Messaging API)を作成
5. チャネル画面の「Messaging API設定」タブで以下をメモ:
   - **チャネルアクセストークン**(長い文字列。「発行」ボタンを押す)
   - **チャネルシークレット**(チャネル基本設定タブにあります)

### 2. Notion側の連携キーを取得する

1. https://www.notion.so/profile/integrations を開く
2. 「新しいインテグレーション」を作成、名前は「みかん狩りLINEbot」など
3. 発行された **シークレットキー**(`ntn_` または `secret_` で始まる文字列)をメモ
4. Notionの「みかん狩り組合 運営」ページを開き、右上の「•••」→「コネクト」から
   このインテグレーションを追加(これをしないとbotがNotionを読めません)

### 3. Cloudflareアカウントを作る

1. https://dash.cloudflare.com/sign-up でアカウント作成(無料)
2. **誰の名義で作るか、誰が管理するか**を組合内で決めておいてください
   (F項目と同じ考え方で、観光協会 or 組合の共有アカウントを推奨)

### 4. このフォルダを使ってデプロイする

パソコンにNode.js(https://nodejs.org/ からインストール)が必要です。
その上で、このフォルダをターミナル(またはコマンドプロンプト)で開いて:

```
npm install
npx wrangler login
```

ブラウザが開いてCloudflareへのログインを求められるので許可します。

次に「秘密の鍵」をCloudflareに登録します(1回だけ):

```
npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
npx wrangler secret put LINE_CHANNEL_SECRET
npx wrangler secret put NOTION_TOKEN
```

それぞれ実行するとターミナルに値を貼り付けるよう聞かれるので、
手順1・2でメモした値を貼り付けます。

最後にデプロイ:

```
npm run deploy
```

成功すると `https://mikangari-line-bot.〇〇.workers.dev` のようなURLが表示されます。
これをメモしてください(Webhook URLになります)。

### 5. LINE側にWebhook URLを設定する

1. LINE Developersコンソールの「Messaging API設定」タブに戻る
2. 「Webhook URL」に `さきほどのURL/webhook` を入力(末尾に`/webhook`を忘れずに)
3. 「Webhookの利用」をオンにする
4. 「応答メッセージ」はオフにする(botの自動応答と重複するため)

### 6. 管理者(石井さん)のユーザーIDを登録する

1. 作った公式アカウントを自分のLINEで友だち追加する
2. 何かメッセージを送る(例:「テスト」)
3. LINE Developersコンソールの「統計情報」やWebhookログで自分のuserIdを確認
   (わからない場合はクロコに聞いてください、確認方法を一緒に探します)
4. `wrangler.toml` の `ADMIN_USER_IDS = ""` の部分に、そのIDを入れて保存
   (複数人いる場合はカンマ区切り)
5. `npm run deploy` でもう一度デプロイし直す

## 各園オーナー向け:休園ボタンの使い方

1. 公式アカウントを友だち追加する
2. 自分の園の名前をそのまま送る(例:「石井園」とだけ送信) → 登録完了の返信が来る
3. 休園する日は、リッチメニュー(下部の帯)の「休園連絡」ボタンをタップするだけ
   (文字入力は不要です)

※リッチメニューの画像・ボタン配置は、LINE Official Account Managerの管理画面
(https://manager.line.biz/)から別途設定します。これは石井さんと相談しながら
後日クロコが手順書を追加します。

---

## お客様向けの使い方(自動)

- 「今日」「当番」などと送ると、本日の当番園を自動で返信
- 「料金」「駐車場」「ペット」などのキーワードにも自動で返信(FAQ)
- 「団体予約」などバス関連のキーワードには「準備中です」と返信(③④は今年度未実装)

Q&Aの内容は、Notionの「LINE bot FAQ」データベースを編集するだけで
更新できます(コードの変更は不要)。

---

## 観光協会向け:休園状況の確認

管理者として登録された人が「休園状況」と送ると、その日の休園連絡が
一覧で返信されます。あわせてNotionの「本日の休園連絡ログ」データベースでも
確認できます。

---

## 安全ルール

1. 石井みかん園単独の門外不出データとは、このbotのデータベースを一切混ぜない
2. 予約者の氏名・電話番号などの個人情報は、今年度は取り扱わない(③④は工事中のため)
3. Notionの編集権限は組合側のみとし、観光協会には閲覧+返信までとする

---

## 困ったとき

- **botが反応しない** → Webhook URLの末尾に`/webhook`が付いているか確認
- **「工事中」ばかり出る** → ③④は今年度は仕様通り(工事中表示が正しい動作)
- **料金やFAQの答えを変えたい** → Notion「LINE bot FAQ」データベースを直接編集
- **新しい園を追加したい/園名を変えたい** → クロコに伝えてください。コードの修正が必要です
