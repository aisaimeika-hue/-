# レシート自動仕分けシステム つかいかた

ザ・作兵衛フルーツガーデン用(フェーズ1: 投函箱方式)

---

## 仕組み(ざっくり)

```
iPhoneでレシート撮影
   ↓ AirDrop
デスクトップの「レシート投函箱」に入れる
   ↓ 「仕分け実行.command」をダブルクリック
クロコが自動で:
   読む → 名付ける → 仕分ける → 記帳する

結果:
  デスクトップ/領収書_整理済み/2026年07月/20260707_カインズ_3480円.jpg
  デスクトップ/領収書_整理済み/経費台帳_2026.csv (自動記帳)
```

**写真は絶対に削除されません。移動するだけです。**

---

## 最初の準備(1回だけ)

### 1. このフォルダをMacに置く

「レシート自動仕分け」フォルダごと、Macの好きな場所に置きます
(デスクトップか「書類」がおすすめ)。

### 2. APIキーを用意する

クロコが写真を読むための「鍵」です。

1. https://console.anthropic.com を開いてログイン(なければ登録)
2. 左メニューの「API Keys」→「Create Key」でキーを作る
3. `sk-ant-` で始まる長い文字列をコピー
4. この「レシート自動仕分け」フォルダの中に **「APIキー.txt」** という
   名前のファイルを作り、コピーした文字列を貼り付けて保存

※ 料金はレシート1枚あたり数円程度です(クレジットカード登録が必要)。
※ APIキーは他人に見せないでください。

### 3. 初回の実行許可

「仕分け実行.command」を初めて開くとき、Macが警告を出すことがあります。
その場合: **右クリック → 「開く」→「開く」** で起動できます。

---

## 毎日の使い方

1. iPhoneでレシートを撮影
2. 写真を選んで **AirDrop → MacBook Air** に送る
3. ダウンロードされた写真を **デスクトップの「レシート投函箱」** に入れる
4. **「仕分け実行.command」をダブルクリック**
5. 結果の報告を確認する
   - ✅ 処理済み → 「領収書_整理済み」に月別で保存+CSV記帳済み
   - ⚠️ 要確認 → 「レシート投函箱/要確認」に入っています。中を見て手動で対応
   - 📷 対象外 → レシートでない写真。「レシート投函箱/対象外」へ移動されただけ

## 経費カテゴリー(自動分類)

肥料費 / 農具費 / 農薬衛生費 / 諸材料費 / 修繕費 / 動力光熱費 /
作業用衣料費 / 車両費 / 荷造運賃手数料 / 雇人費 / 消耗品費 /
接待交際費 / 通信費 / 雑費 / 不明(判定に迷ったとき)

判定に迷ったものは勝手に決めず「不明」になり、備考欄に候補が書かれます。

---

## 安全ルール

1. 写真の削除は絶対にしない(移動のみ)
2. レシート以外の写真の中身は読み取らない・記録しない
3. 金額・日付が読み取れないときは推測せず「要確認」へ回す

---

## 困ったとき

- **「APIキーが見つかりません」と出る**
  → 「APIキー.txt」の中身が正しく貼れているか確認
- **CSVをExcelで開くと文字化けする**
  → しないはずですが、もし化けたら教えてください
- **要確認が多い**
  → 撮影のコツ: 明るい場所で、レシート全体が写るように、真上から撮る
