# みかん狩り組合 WEB案内 つかいかた

2026年度シーズン向け(①当番照会・FAQ フル実装/②休業連絡 簡易版/③④は工事中表示)

LINE公式アカウントは使わず、**ウェブページ**として作り直したバージョンです。
LINE Developer登録が不要になり、構築がぐっとシンプルになりました。

---

## 仕組み(ざっくり)

```
お客様がスマホでURL(またはQRコード)を開く
   ↓
クロコ(サーバー)がNotionの当番表を見に行く
   ↓
「本日の当番は◯◯園です」が画面に表示される

各園のオーナーが、自分専用のURL(ブックマーク)を開いてボタンを押す
   ↓
Notionの休園連絡ログに自動記録
   ↓
観光協会が管理者用URLを開くと一覧で確認できる
```

このページ自体はClaude Codeが書いたものですが、**24時間表示できる場所(サーバー)**が別途必要です。前回同様、Cloudflare(クラウドフレア)という会社の無料サービスを使います。

---

## 最初の準備(1回だけ)

### 1. Notion側の連携キーを取得する

(LINE botの時と同じです。すでに終わっている場合はスキップしてください)

1. https://www.notion.so/profile/integrations を開く
2. 「新しいインテグレーション」を作成、名前は「みかん狩りWEB案内」など
3. 発行された**シークレットキー**(`ntn_` または `secret_` で始まる文字列)をメモ
4. Notionの「みかん狩り組合 運営」ページを開き、右上の「•••」→「コネクト」から
   このインテグレーションを追加

### 2. Cloudflareアカウントを作る

1. https://dash.cloudflare.com/sign-up でアカウント作成(無料)
2. 誰の名義で作るか、誰が管理するかを組合内で決めておいてください

### 3. このフォルダを使ってデプロイする

パソコンにNode.js(https://nodejs.org/ からインストール)が必要です。
その上で、このフォルダをターミナル(またはコマンドプロンプト)で開いて:

```
npm install
npx wrangler login
```

ブラウザが開いてCloudflareへのログインを求められるので許可します。

次に「秘密の鍵」を登録します(1回だけ):

```
npx wrangler secret put NOTION_TOKEN
```

手順1でメモした値を貼り付けます。

管理者用ページのパスワード代わりの合言葉も決めて登録します:

```
npx wrangler secret put ADMIN_KEY
```

好きな英数字の文字列(例:`mikan2026admin`)を入力してください。これが後で
管理者用URLの合言葉になります。

最後にデプロイ:

```
npm run deploy
```

成功すると `https://mikangari-web.〇〇.workers.dev` のようなURLが表示されます。
これがそのままお客様に案内するURLになります。

## お客様向けの使い方

上記URLを開くだけです。今日の当番園とFAQが表示されます。

**QRコードにして三浦海岸駅の観光案内所やチラシに掲載する**と、お客様がその場で
スマホをかざすだけで見られるようになります。QRコード自体は
https://www.qr-code-generator.com/ などの無料サービスでURLから作成できます
(クロコに頼めば別途作成もできます)。

---

## 各園オーナー向け:休園連絡ページ

各園には専用のURLがあります(下記一覧)。ブックマークしておいて、休園する日に
開いて「本日休園を連絡する」ボタンを押すだけです。文字入力は不要です。

```
https://(デプロイ後のURL)/kyuen/okumoto   → 奥本園
https://(デプロイ後のURL)/kyuen/yamasa    → ヤマサ園
https://(デプロイ後のURL)/kyuen/okayasu   → 岡安園
https://(デプロイ後のURL)/kyuen/yoshida   → 吉田園
https://(デプロイ後のURL)/kyuen/ishii     → 石井園
https://(デプロイ後のURL)/kyuen/shimoto   → しもと園
https://(デプロイ後のURL)/kyuen/iijima    → 飯島園
https://(デプロイ後のURL)/kyuen/shindo    → 進藤園
https://(デプロイ後のURL)/kyuen/maruyu    → 丸ユ園
```

各園のオーナーに、それぞれのURLをLINEやメールで伝えて、スマホのホーム画面に
追加(ブックマーク)してもらってください。

---

## 観光協会向け:休園状況の確認

以下のURLを開くと、その日の休園連絡が一覧で見られます(`合言葉`部分は
`ADMIN_KEY`に設定した文字列に置き換えてください)。

```
https://(デプロイ後のURL)/status?key=合言葉
```

このURLは関係者以外に教えないでください。

## Q&Aの内容を変えたい

Notionの「LINE bot FAQ」データベースを編集するだけで更新できます(コードの変更は不要)。
データベース名は今も「LINE bot FAQ」のままですが、中身はこのWEB案内でも使っています。

---

## 安全ルール

1. 石井みかん園単独の門外不出データとは、このシステムのデータベースを一切混ぜない
2. 予約者の氏名・電話番号などの個人情報は、今年度は取り扱わない(③④は工事中のため)
3. `/status`の合言葉は関係者以外に共有しない

---

## 困ったとき

- **ページが表示されない** → デプロイが成功しているか(`npm run deploy`の結果)を確認
- **「工事中」ばかり出る** → ③④は今年度は仕様通り(工事中表示が正しい動作)
- **料金やFAQの答えを変えたい** → Notion「LINE bot FAQ」データベースを直接編集
- **新しい園を追加したい/園名を変えたい** → クロコに伝えてください。コードの修正が必要です
- **LINE版に戻したい** → 前のバージョンはgitの履歴に残っているので復元可能です
